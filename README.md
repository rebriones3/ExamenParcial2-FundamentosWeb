# Verde Saludable

Pagina web de un restaurante de comida saludable. Muestra el menu, los beneficios de comer sano, productos destacados, informacion del restaurante y datos de contacto.

## Autora

Ruth Estefany Briones Moreira

## Tecnologias utilizadas

- HTML5 - Estructura del sitio
- CSS3 - Estilos personalizados
- Bootstrap 5.3.8 - Componentes y diseno responsivo

## Secciones de la pagina

1. Inicio - Presentacion principal del restaurante
2. Beneficios - Por que elegir Verde Saludable (rica, bonita y barata)
3. Productos - Platos destacados con tarjetas (Plato 1, 2 y 3)
4. Nuestra mision - Informacion sobre el restaurante
5. Reserva - Llamado a la accion para reservar
6. Footer - Contacto, enlaces y redes sociales

## Como verlo

1. Descarga o clona la carpeta del proyecto.
2. Abre el archivo index.html en tu navegador.
3. Listo. Ya puedes navegar por el sitio.
